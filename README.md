## مدیریت دوره‌ها و مقالات در نسخهٔ ۲.۳

خانم منتظری می‌تواند از مسیر `/admin/` وارد «مدیریت آموزشگاه» شود. همین مسیر در سایت‌های مستقر در زیردایرکتوری، زیر نشانی اصلی همان سایت قرار می‌گیرد. برای مثال اگر نشانی سایت به `/dayan-hesabdar/` ختم شود، نشانی ورود `/dayan-hesabdar/admin/` است.

### استفادهٔ روزمره برای مدیر آموزشگاه

1. از «ورود به پنل مدیریت» با ایمیل دعوت‌شده وارد Pages CMS شوید و «مدیریت آموزشگاه» را باز کنید.
2. زیر «دوره‌های آموزشی» دکمهٔ افزودن (+) را بزنید یا نام یکی از دوره‌ها را باز کنید. نام، معرفی و سرفصل‌ها را بنویسید. برای هر شیوهٔ برگزاری، «این شیوه برگزار می‌شود» را فعال کنید و شهریه را به **تومان** وارد کنید. صفر به معنی رایگان است. هر ویژگی و هر مبحث را در یک خط بنویسید.
3. برای یک نوشتهٔ رایگان، زیر «مقالات و آموزش‌های رایگان» یک مطلب با عنوان و متن بسازید. می‌توانید لینک فایل یا ویدیوی مکمل را هم وارد کنید.
4. با روشن کردن «نمایش در سایت» و زدن **Save**، انتشار آغاز می‌شود. پس از پایان انتشار، صفحهٔ عمومی را تازه کنید. برای برداشتن یک مطلب از سایت، همین گزینه را خاموش و ذخیره کنید. ترتیب دوره‌ها در فرم، ترتیب نمایش آن‌ها در فهرست است و سه دورهٔ اولِ منتشرشده در صفحهٔ اصلی دیده می‌شوند.
5. در «مشخصات آموزشگاه» نام، نشانی کلاس حضوری و عکس معرفی را تغییر دهید. عکس جدید را در کتابخانهٔ «عکس‌های معرفی» بارگذاری و انتخاب کنید. با پاک‌کردن انتخاب، عکس اصلی خانم منتظری نمایش داده می‌شود.

دو دورهٔ اصول حسابداری و حقوق و دستمزد برای نمایش آماده‌اند. شش عنوان نسخهٔ قبل در پنل به‌صورت پیش‌نویس نگهداری می‌شوند. بخش مقالات با انتشار اولین مطلب مدیر پُر می‌شود.

### فعال‌سازی یک‌باره توسط مالک مخزن

1. تغییرات این نسخه، شامل فایل `.pages.yml` و گردش کار انتشار، را با GitHub Desktop به شاخهٔ `main` مخزن `sdhadi/dayan-hesabdar` بفرستید.
2. در **Settings → Pages → Build and deployment → Source** گزینهٔ **GitHub Actions** را انتخاب کنید. برای انتشار اولیه از **Actions → Publish academy website → Run workflow** استفاده کنید. نشانی سایت پس از اجرای موفق در تنظیمات Pages دیده می‌شود. [تنظیمات Pages همین مخزن](https://github.com/sdhadi/dayan-hesabdar/settings/pages) · [راهنمای انتشار در GitHub](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages)
3. با حساب GitHub مالک در Pages CMS وارد شوید. هنگام نصب GitHub App، **Only select repositories** و همین مخزن را انتخاب کنید. سپس در **Collaborators**، ایمیل خانم منتظری را دعوت کنید. دعوت‌شده از طریق ایمیل احراز هویت می‌شود. حق ویرایش محتوا را Pages CMS برای همین مخزن بررسی می‌کند. [ورود به Pages CMS](https://app.pagescms.org/) · [راهنمای دعوت و دسترسی ویراستار](https://pagescms.org/docs/configuration/collaborators/)
4. نشانی `/admin/` سایت را به مدیر بدهید. نخستین ذخیره را با یک پیش‌نویس انجام دهید و وضعیت گردش کار را در GitHub Actions ببینید. برای بازگرداندن یک ویرایش اشتباه، مالک مخزن می‌تواند کامیت مربوط به محتوا را در Git برگرداند.

### ساخت نسخهٔ قابل میزبانی

فرم مدیریت، داده‌های `site_content.json` را در شاخهٔ `main` ذخیره می‌کند. گردش کار با هر تغییر محتوایی، یک خروجی استاتیک شامل دوره‌ها و مقالات منتشرشده می‌سازد. پیش‌نویس‌ها در مخزن منبع وجود دارند و سطح دسترسی به خود مخزن تابع تنظیمات GitHub است.

با Node.js ۲۰ یا جدیدتر از ریشهٔ مخزن اجرا کنید.

```sh
node scripts/build-site.mjs
```

فایل `dist/index.html` شامل محتوای عمومی، فونت و عکس معرفی است. پوشهٔ `dist/admin/` مسیر ورود را فراهم می‌کند. روی هر میزبان استاتیک می‌توانید محتوای `dist/` را منتشر کنید. برای انتشار خودکار روی میزبانی دیگر، همان میزبان را به شاخهٔ `main` وصل کنید، دستور بالا را به‌عنوان فرمان ساخت و `dist` را به‌عنوان مسیر خروجی بدهید.

در پیش‌نمایش HTTP ریشهٔ پروژه، سایت داده‌ها را از JSON مجاور می‌خواند. باز کردن مستقیم `index.html` از روی دیسک، تصویر ذخیره‌شدهٔ محتوای زمان ساخت را نشان می‌دهد. هنگام تحویل نسخهٔ شماره‌دار، پیش از گرفتن کپی آرشیوی، آن را با دستور زیر تازه کنید.

```sh
node scripts/build-site.mjs --refresh-snapshot
```

## 🔗 راهنمای گام‌به‌گام جداسازی دامنه `dayanhesabdar.ir` از سایت‌ساز پرتال و اتصال به سایت جدید

بر اساس مستندات رسمی [آموزش تغییر DNS بر روی دامنه سایت در پرتال](https://www.portal.ir/how-to-change-dns)، [آموزش ثبت شناسه nic و تنظیم رابط‌های مجاز در ایرنیک](https://www.portal.ir/visual-guide-for-register-nic-id) و [راهنمای انتقال و جابه‌جایی دامنه ir در ایرنیک (پارس‌پک)](https://parspack.com/blog/domain/national/transfer-domain-ir-irnic)، فرآیند فنی به شرح زیر است:

### ۱. وضعیت مالکیت دامنه `.ir` (تفاوت «جابه‌جایی DNS» با «انتقال مالکیت»)
- در دامنه‌های ملی (`.ir`)، مالک قانونی دامنه (`Holder`) در سامانه ایرنیک (`nic.ir`) خودِ شخص متقاضی (خانم مرضیه منتظری با شناسه ایرنیک شخصی ایشان) است و سایت‌ساز پرتال صرفاً از طریق بخش «رابط‌های مجاز (آزاد برای نمایندگان فروش)» دامنه را ثبت و نیم‌سرورهای (`NS`) خود را روی آن قرار داده است ([راهنمای رابط‌های مجاز ایرنیک در پرتال](https://www.portal.ir/visual-guide-for-register-nic-id)).
- بنابراین برای راه‌اندازی سایت جدید، **هیچ نیازی به انتقال مالکیت یا دریافت کد انتقال (PIN) نیست**؛ بلکه صرفاً باید در پنل ایرنیک، **جابه‌جایی دامنه (تغییر DNS / Name Server)** انجام شود ([تفاوت جابه‌جایی و انتقال دامنه در ایرنیک](https://parspack.com/blog/domain/national/transfer-domain-ir-irnic)).

### ۲. چهار گام اجرایی برای اتصال `dayanhesabdar.ir` به وب‌سایت جدید
1. **گام اول — ورود به پنل ایرنیک (`nic.ir`):**
   - با شناسه کاربری ایرنیک خانم منتظری (به فرمت `xxxx-irnic`) یا ایمیل ایشان و گذرواژه وارد سایت `nic.ir` شوید ([آموزش تغییر DNS در ایرنیک](https://www.portal.ir/how-to-change-dns)).
2. **گام دوم — اعطای نقش «رابط فنی» به شناسه ایرنیک شما (توصیه‌شده برای مدیریت راحت):**
   - در پنل ایرنیک خانم منتظری، از منوی بالا وارد **«دامنه‌ها» -> «دامنه‌های من»** شوید، دامنه `dayanhesabdar.ir` را انتخاب کرده و در بخش **«تغییر رابط‌ها»**، شناسه ایرنیک خودتان (سید هادی موسوی) را به عنوان **«رابط فنی (Technical Contact)»** وارد کنید. با این کار، از این پس بدون نیاز به ورود به اکانت ایشان، می‌توانید مستقیماً از پنل ایرنیک خودتان DNSهای دامنه را مدیریت کنید ([آموزش مدیریت رابط‌های مجاز در ایرنیک](https://www.portal.ir/visual-guide-for-register-nic-id)).
3. **گام سوم — انتخاب سرویس میزبانی (Hosting) برای فاز ۱ استاتیک:**
   - **گزینه الف (معماری ابری رایگان + CDN ایرانی — مشابه تجربه موفق شما در `kingfarmer.ir`):** انتشار خروجی ساخت از طریق **GitHub Pages** (یا Cloudflare Pages) طبق راهنمای بالا و ثبت دامنه `dayanhesabdar.ir` در پنل **ابر آروان (ArvanCloud)** برای دریافت ۲ نیم‌سرور آروان، گواهی SSL رایگان و بارگذاری پرسرعت در ایران.
   - **گزینه ب (هاست لینوکس اقتصادی ایرانی — مانند نت‌افراز / پارس‌پک):** خرید یک هاست لینوکس پایه (مثلاً در نت‌افراز که قبلاً در `kingfarmer.ir` استفاده کرده‌اید) و آپلود محتوای پوشهٔ ساخته‌شدهٔ `dist/` در پوشهٔ `public_html`.
4. **گام چهارم — جایگزینی Name Serverها در ایرنیک:**
   - طبق [راهنمای تصویری تغییر DNS دامنه `.ir`](https://www.portal.ir/how-to-change-dns)، در صفحه دامنه `dayanhesabdar.ir` در ایرنیک روی دکمه **«ویرایش ردیف‌های کارگزاری نام و میزبانی دامنه»** کلیک کنید.
   - در ستون «نام کارگزار (NS Record)»، نیم‌سرورهای قبلی پرتال را پاک کرده و دو نیم‌سرور جدید (مثلاً نیم‌سرورهای ابر آروان یا هاست نت‌افراز) را در ردیف ۱ و ۲ وارد کنید (بخش آی‌پی کارگزار نیازی به پر کردن ندارد).
   - پاسخ محرمانه (`Secret Answer`) حساب ایرنیک را وارد کرده و دکمه **«اعمال»** را بزنید. بین ۴ تا ۲۴ ساعت بعد، دامنه از پرتال جدا شده و وب‌سایت جدید شما را نمایش می‌دهد.

git branch -M main
git add .
git commit -m "feat(init): scaffold Dayan Hesabdari v1.0 static website and AI-Native docs [Argon-Gemini-sd.hadi.mousavi]"
