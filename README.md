## 🔗 راهنمای گام‌به‌گام جداسازی دامنه `dayanhesabdar.ir` از سایت‌ساز پرتال و اتصال به سایت جدید

بر اساس مستندات رسمی [آموزش تغییر DNS بر روی دامنه سایت در پرتال](https://www.portal.ir/how-to-change-dns)، [آموزش ثبت شناسه nic و تنظیم رابط‌های مجاز در ایرنیک](https://www.portal.ir/visual-guide-for-register-nic-id) و [راهنمای انتقال و جابه‌جایی دامنه ir در ایرنیک (پارس‌پک)](https://parspack.com/blog/domain/national/transfer-domain-ir-irnic)، فرآیند فنی به شرح زیر است:

### ۱. وضعیت مالکیت دامنه `.ir` (تفاوت «جابه‌جایی DNS» با «انتقال مالکیت»)
- در دامنه‌های ملی (`.ir`)، مالک قانونی دامنه (`Holder`) در سامانه ایرنیک (`nic.ir`) خودِ شخص متقاضی (خانم مرضیه منتظری با شناسه ایرنیک شخصی ایشان) است و سایت‌ساز پرتال صرفاً از طریق بخش «رابط‌های مجاز (آزاد برای نمایندگان فروش)» دامنه را ثبت و نیم‌سرورهای (`NS`) خود را روی آن قرار داده است ([راهنمای رابط‌های مجاز ایرنیک در پرتال](https://www.portal.ir/visual-guide-for-register-nic-id)).
- بنابراین برای راه‌اندازی سایت جدید، **هیچ نیازی به انتقال مالکیت یا دریافت کد انتقال (PIN) نیست**؛ بلکه صرفاً باید در پنل ایرنیک، **جابه‌جایی دامنه (تغییر DNS / Name Server)** انجام شود ([تفاوت جابه‌جایی و انتقال دامنه در ایرنیک](https://parspack.com/blog/domain/national/transfer-domain-ir-irnic)).

### ۲. چهار گام اجرایی برای اتصال `dayanhesabdar.ir` به وب‌سایت جدید
1. **گام اول — ورود به پنل ایرنیک (`nic.ir`):**
   - با شناسه کاربری ایرنیک خانم منتظری (به فرمت `xxxx-irnic`) یا ایمیل ایشان و گذرواژه وارد سایت `nic.ir` شوید ([آموزش تغییر DNS در ایرنیک](https://www.portal.ir/how-to-change-dns)).
2. **گام دوم — اعطای نقش «رابط فنی» به شناسه ایرنیک شما (توصیه‌شده برای مدیریت راحت):**
   - در پنل ایرنیک خانم منتظری، از منوی بالا وارد **«دامنه‌ها» -> «دامنه‌های من»** شوید، دامنه `dayanhesabdar.ir` را انتخاب کرده و در بخش **«تغییر رابط‌ها»**، شناسه ایرنیک خودتان (سید هادی موسوی) را به عنوان **«رابط فنی (Technical Contact)»** وارد کنید. با این کار، از این پس بدون نیاز به ورود به اکانت ایشان، می‌توانید مستقیماً از پنل ایرنیک خودتان DNSهای دامنه را مدیریت کنید ([آموزش مدیریت رابط‌های مجاز در ایرنیک](https://www.portal.ir/visual-guide-for-register-nic-id)).
3. **گام سوم — انتخاب سرویس میزبانی (Hosting) برای فاز ۱ استاتیک:**
   - **گزینه الف (معماری ابری رایگان + CDN ایرانی — مشابه تجربه موفق شما در `kingfarmer.ir`):** قرار دادن فایل `index.html` در یک مخزن **GitHub Pages** (یا Cloudflare Pages) و ثبت دامنه `dayanhesabdar.ir` در پنل **ابر آروان (ArvanCloud)** برای دریافت ۲ نیم‌سرور آروان، گواهی SSL رایگان و بارگذاری پرسرعت در ایران.
   - **گزینه ب (هاست لینوکس اقتصادی ایرانی — مانند نت‌افراز / پارس‌پک):** خرید یک هاست لینوکس پایه (مثلاً در نت‌افراز که قبلاً در `kingfarmer.ir` استفاده کرده‌اید) و آپلود فایل `index.html` در پوشه `public_html`.
4. **گام چهارم — جایگزینی Name Serverها در ایرنیک:**
   - طبق [راهنمای تصویری تغییر DNS دامنه `.ir`](https://www.portal.ir/how-to-change-dns)، در صفحه دامنه `dayanhesabdar.ir` در ایرنیک روی دکمه **«ویرایش ردیف‌های کارگزاری نام و میزبانی دامنه»** کلیک کنید.
   - در ستون «نام کارگزار (NS Record)»، نیم‌سرورهای قبلی پرتال را پاک کرده و دو نیم‌سرور جدید (مثلاً نیم‌سرورهای ابر آروان یا هاست نت‌افراز) را در ردیف ۱ و ۲ وارد کنید (بخش آی‌پی کارگزار نیازی به پر کردن ندارد).
   - پاسخ محرمانه (`Secret Answer`) حساب ایرنیک را وارد کرده و دکمه **«اعمال»** را بزنید. بین ۴ تا ۲۴ ساعت بعد، دامنه از پرتال جدا شده و وب‌سایت جدید شما را نمایش می‌دهد.

## 💻 راه‌اندازی Git و GitHub روی Google Drive for Desktop

برای اتصال این پوشه در ویندوز به گیت و گیت‌هاب (بدون کند شدن همگام‌سازی گوگل درایو با فایل‌های سنگین `.git/`)، از دستور `--separate-git-dir` استفاده کنید:

```powershell
cd "G:\My Drive\#دایان حسابداری (Dayan_Hesabdar)#"
git init --separate-git-dir="$HOME\.git-repos\dayan-hesabdar.git"
git branch -M main
git add .
git commit -m "feat(init): scaffold Dayan Hesabdari v1.0 static website and AI-Native docs [Argon-Gemini-sd.hadi.mousavi]"
```
